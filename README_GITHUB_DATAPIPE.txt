DATA SAVING
- Uses @jspsych/extension-pipe v0.2.0.
- Each completed participant is saved to Google Drive through DataPipe as a unique CSV.
- Streaming is ON by default, so completed trials from dropouts can be recovered as partial data.

TOPIC ASSIGNMENT
- DataPipe condition 0 = Topic A
- DataPipe condition 1 = Topic B
- DataPipe condition assignment is SEQUENTIAL (0,1,0,1...), not random.
- O/C/N stimulus order is randomized locally for each participant.
- Both the 10 trait-item rows and the semantic-differential rows are randomized independently for each stimulus.

BEFORE TESTING
1. Upload all files in this ZIP to the root of your GitHub repository.
2. Enable GitHub Pages from main / root.
3. In DataPipe, turn ON "Accept new data".
4. Open the GitHub Pages URL and submit one full test.
5. Verify the CSV appears in the connected Google Drive folder.
